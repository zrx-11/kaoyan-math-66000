第 0 题 逼近·偶次二次匹配 P109

在 \(x=0\) 附近用 \(Y(x)=a+bx^{2}\) 近似 \(\dfrac{\sin x}{x}\)，使误差为 \(o(x^{2})\)，求 a,b。

答案：\(a=1\)，\(b=-\dfrac{1}{6}\)。商式在 \(x=0\) 处按极限补定义为 1，其偶次 Taylor 展开与多项式逐项对表，常数项与二次项分别锁定。
解析

识别类型：可去奇点处商函数的 Taylor 逼近。多项式只含常数项与 \(x^{2}\) 项，误差 \(o(x^{2})\) 要求常数、一次、二次三级系数全部对齐，缺一级即无解。

\[ \sin x=x-\frac{x^{3}}{6}+O(x^{5}),\qquad \frac{\sin x}{x}=1-\frac{x^{2}}{6}+O(x^{4}). \]

与 \(Y(x)=a+bx^{2}\) 逐级比较：常数项 \(a=1\)；一次项两侧均为 0，自动对齐；二次项给出 \(b=-\dfrac{1}{6}\)。匹配方程组写开即

\[ a=1,\qquad 0=0,\qquad b=-\frac{1}{6}. \] \[ Y(x)-\frac{\sin x}{x}=\frac{x^{4}}{120}+O(x^{6})=o(x^{2}). \]

代入复核：配好系数后残余只从 \(x^{4}\) 项起，除以任意 \(x^{2}\) 量级仍趋于 0，满足 \(o(x^{2})\)；若 \(a\) 不取 1，误差在 \(x\to0\) 时趋于非零常数，不属 \(o(x^{2})\)。

整条路径不涉及高阶导数估计，只靠逐项对表；凡目标函数在 0 处有定义或可补定义，逼近题都先写前若干级 Taylor 再列系数方程。

易错点

① 漏掉常数项：\(\sin x/x\) 在 0 处的极限是 1，多项式常数项必须取 1，不能只配二次项。

② 把 \(o(x^{2})\) 当成只对齐到 \(x\)：二次系数 \(b\) 同样被锁定为 \(-1/6\)，不是自由参数。

③ 商式在 \(x=0\) 本无定义，逼近的前提是先按极限补定义为 1，再谈展开。

考向

可去奇点处的偶次商式（\(\sin x/x\)、\(\tan x/x\)、\((1-\cos x)/x^{2}\)）都先补定义再展开。判断有无解的固定动作：列出目标函数 \(1,x,x^{2},\dots\) 各级系数，多项式缺哪一级就查目标函数该级是否为 0，非零即无解；偶次多项式配偶次目标、奇次多项式配奇次目标，奇偶错位同样无解。

变式

变式 取 \(a=1\)、\(b=-1/6\) 后，写出本题误差的主部与阶数；该阶是否满足 \(o(x^{2})\)？

答案：主部 \(x^{4}/120\)，属 \(O(x^{4})\)，除以 \(x^{2}\) 得 \(x^{2}/120\to0\)，满足 \(o(x^{2})\)；只有把口径压到 \(o(x^{4})\) 时，才需要补入 \(x^{4}\) 项并取系数 \(1/120\)。

第 0 题 逼近·指数嵌套 P109

【冯建轩】在 \(x=0\) 附近用 \(Z(x)=a+bx+cx^{2}\) 近似 \(e^{\sin x}\)，使误差为 \(o(x^{2})\)，求 a,b,c。

答案：\(a=1\)，\(b=1\)，\(c=\dfrac{1}{2}\)。内层 \(\sin x\) 先展开，再代入指数函数的 Taylor 级数，三级系数逐项对表即得。
解析

识别类型：复合函数的 Taylor 逼近。先把内层 \(\sin x\) 写到所需阶数，再用 \(e^{u}=1+u+u^{2}/2+O(u^{3})\) 回代，误差 \(o(x^{2})\) 要求常数、一次、二次三级全部对齐。

\[ \sin x=x+O(x^{3}),\qquad e^{u}=1+u+\frac{u^{2}}{2}+O(u^{3}). \]

回代后 \(u=x+O(x^{3})\)，\(u^{2}=x^{2}+O(x^{4})\)，于是

\[ e^{\sin x}=1+x+\frac{x^{2}}{2}+O(x^{3}). \]

与 \(Z(x)=a+bx+cx^{2}\) 逐级比较：常数项 \(a=1\)，一次项 \(b=1\)，二次项 \(c=1/2\)。匹配方程组为

\[ a=1,\qquad b=1,\qquad c=\frac{1}{2}. \]

代入复核：配好后 \(x^{3}\) 级系数亦为 0，残余从 \(x^{4}\) 项起，整体 \(O(x^{4})=o(x^{2})\)。若二次项系数不取 \(1/2\)，残余主部为 \(x^{2}\) 量级，除以 \(x^{2}\) 不趋于 0，不满足题设误差阶。

易错点

① 复合展开漏层：只展 \(\sin x\) 就回代，丢掉 \(u^{2}/2\) 贡献的 \(x^{2}/2\)，二次系数会算成 0。

② 把 \(e^{\sin x}\) 的常数项当成 \(\sin 0=0\)：指数函数在 0 处取值为 1，常数项必须取 1。

③ 高阶项照抄：\(\sin x\) 的 \(-x^{3}/6\) 在本题 \(o(x^{2})\) 口径下不影响前三级，不必代入二次系数。

考向

嵌套型逼近（\(e^{\sin x}\)、\(e^{\tan x}\)、\(\ln(1+\sin x)\)）一律由内向外展开：先写内层到目标阶数，再套外层级数，平方项、乘积项都要保留到同阶。同一骨架换外层函数（\(\cos\)、\(\ln\)、\(\arctan\)）时，对表方法不变，只换各级系数。

变式

变式 取 \(a=1\)、\(b=1\)、\(c=1/2\) 后，本题误差主部是几阶？若口径提到 \(o(x^{3})\)，现有二次多项式是否够用？

答案：目标 \(x^{3}\) 系数为 0，配好二次项后残余主部为 \(-x^{4}/8\)，属 \(O(x^{4})=o(x^{3})\)；口径提到 \(o(x^{3})\) 时现有多项式仍够用，只有提到 \(o(x^{4})\) 才需补 \(x^{4}\) 项，系数 \(-1/8\)。

第 0 题 逼近·高阶起项 P109

【冯建轩】在 \(x=0\) 附近用 \(A(x)=ax+bx^{2}\) 近似 \(\tan x-\sin x\)，使误差为 \(o(x^{2})\)，求 a,b。

答案：\(a=0\)，\(b=0\)。目标函数常数、一次、二次三级系数全为 0，多项式被对齐成零多项式，残余主部 \(x^{3}/2\) 仍属 \(o(x^{2})\)。
解析

识别类型：目标函数从高阶项才起非零系数的逼近题。先分别展开 \(\tan x\) 与 \(\sin x\)，相减后看前三级是否为 0，再与 \(A(x)=ax+bx^{2}\) 对表。

\[ \tan x=x+\frac{x^{3}}{3}+O(x^{5}),\qquad \sin x=x-\frac{x^{3}}{6}+O(x^{5}). \]

两式相减，一次项抵消，二次项两侧本就为 0：

\[ \tan x-\sin x=\left(\frac{1}{3}+\frac{1}{6}\right)x^{3}+O(x^{5})=\frac{x^{3}}{2}+O(x^{5}). \]

误差 \(o(x^{2})\) 要求对齐到 \(x^{2}\)：常数项两侧均为 0；一次项 \(a=0\)；二次项 \(b=0\)。匹配方程组为

\[ a=0,\qquad b=0. \]

代入复核：\(A\equiv0\)，误差即目标函数本身，主部 \(x^{3}/2\)，除以 \(x^{2}\) 得 \(x/2\to0\)，确为 \(o(x^{2})\)。本题解出零多项式并不矛盾，因为目标函数在 0 附近本就从三阶才起量。

易错点

① 看到求 a,b 就假定二者非零：目标函数低阶全零时，对齐结果就是 \(a=b=0\)，属正常解。

② 相减时符号出错：\(\tan x-\sin x\) 的三次系数是 \(1/3+1/6=1/2\)，不是 \(1/3-1/6\)。

③ 误判无解：多项式缺 \(x^{3}\) 项不影响本题，因为误差口径只到 \(o(x^{2})\)，三阶起的残余天然合格。

考向

「目标函数低阶全零、多项式配低次项」的题，先确认误差口径停在哪一阶：口径只到 \(x^{2}\) 时，三阶起量的目标函数用零多项式即可合格；若口径收紧到 \(o(x^{3})\)，才必须补 \(x^{3}\) 项。同类骨架还有 \(\sin x-x\)、\(\arctan x-x\)，都从三阶起非零系数。

变式

变式 若把多项式改为 \(ax^{2}+bx^{3}\) 近似 \(\tan x-\sin x\)，误差要求收紧为 \(o(x^{3})\)，求 a,b。

答案：\(a=0\)，\(b=1/2\)。目标函数 \(x^{2}\) 系数为 0 故 \(a=0\)，\(x^{3}\) 系数 \(1/2\) 故 \(b=1/2\)，残余 \(O(x^{5})=o(x^{3})\)。

第 0 题 逼近·o(1)自由度 P109

【冯建轩】在 \(x=0\) 附近用 \(B(x)=a+bx^{2}\) 近似 \(\dfrac{1-\cos x}{x^{2}}\)，使误差为 \(o(1)\)，求 a,b。

答案：\(a=\dfrac{1}{2}\)，\(b\) 任意。误差写成 \(o(1)\) 只要求误差趋于 0，即常数项对齐；\(x^{2}\) 级系数不在约束内，\(b\) 无法由题面唯一确定。
解析

识别类型：误差阶为 \(o(1)\) 的低口径逼近。\(o(1)\) 只要求 \(x\to0\) 时误差趋于 0，等价于常数项对齐，一次及以上各级系数均可自由，解题时必须如实写明哪个系数被定、哪个自由。

\[ 1-\cos x=\frac{x^{2}}{2}-\frac{x^{4}}{24}+O(x^{6}). \]

除以 \(x^{2}\)（在 0 处按极限补定义）：

\[ \frac{1-\cos x}{x^{2}}=\frac{1}{2}-\frac{x^{2}}{24}+O(x^{4}). \]

与 \(B(x)=a+bx^{2}\) 比较：误差趋于 0 只约束常数项 \(a=1/2\)；二次项两侧之差为 \(b+1/24\)，该项乘 \(x^{2}\) 后随 \(x\to0\) 趋于 0，不影响 \(o(1)\)。

\[ a=\frac{1}{2},\qquad b\in\mathbb{R}\ \text{任意}. \]

自由度说明：题面没有给出 \(o(x^{2})\) 或更高口径，\(b\) 取任何实数，误差主部都是 \(x^{2}\) 量级，仍趋于 0；若要锁死 \(b\)，需把误差要求提高到 \(o(x^{2})\)，那时 \(b=-1/24\)。

易错点

① 把 \(o(1)\) 当成 \(o(x^{2})\)：擅自对齐二次项，会把自由的 \(b\) 误算成 \(-1/24\)。

② 漏算常数极限：\((1-\cos x)/x^{2}\) 在 0 处极限为 \(1/2\)，不是 1，也不是 0。

③ 条件不足时硬凑唯一解：应明确写出 \(b\) 任意及原因，而不是给一个没有依据的定值。

考向

误差口径决定自由度数：\(o(1)\) 只锁常数项，\(o(x)\) 锁到一次项，\(o(x^{k})\) 锁到 \(x^{k}\) 项。题面写「求 a,b」但口径低于系数个数时，答案必须分级交代：被口径锁住的写定值，超出口径的写明任意。反问题常考「把口径从 \(o(1)\) 提高到 \(o(x^{2})\) 后系数如何被追加锁定」。

变式

变式 承本题，若把误差要求从 \(o(1)\) 收紧为 \(o(x^{2})\)，\(b\) 应取何值？此时残余主部是几阶？

答案：\(b=-1/24\)。对齐到二次项后残余为 \(O(x^{4})\)，主部 \(x^{4}/720\)；口径提到 \(o(x^{2})\) 后 \(b\) 不再自由，若再提到 \(o(x^{4})\) 才需要补 \(x^{4}\) 项。

第 0 题 逼近·乘积展开 P109

【冯建轩】在 \(x=0\) 附近用 \(C(x)=a+bx+cx^{2}\) 近似 \(e^{x}\cos x\)，使误差为 \(o(x^{2})\)，求 a,b,c。

答案：\(a=1\)，\(b=1\)，\(c=0\)。两因子分别展开后相乘，常数、一次、二次三级系数逐项对表，二次项恰相消为 0。
解析

识别类型：两函数乘积的 Taylor 逼近。先把 \(e^{x}\) 与 \(\cos x\) 都写到二次项，相乘时只保留不超过二次的部分，高于二次的项并入余项。

\[ e^{x}=1+x+\frac{x^{2}}{2}+O(x^{3}),\qquad \cos x=1-\frac{x^{2}}{2}+O(x^{4}). \]

相乘并截断到二次：常数项 \(1\)；一次项只来自 \(1\cdot x\)；二次项来自 \(x^{2}/2\) 与 \(-x^{2}/2\) 两部分，恰好相消。

\[ e^{x}\cos x=1+x+0\cdot x^{2}+O(x^{3}). \]

与 \(C(x)=a+bx+cx^{2}\) 逐级比较，匹配方程组为

\[ a=1,\qquad b=1,\qquad c=0. \]

代入复核：配好后残余主部为 \(-x^{3}/3\)，整体 \(O(x^{3})=o(x^{2})\)。二次项相消是本题关键，若只凭 \(e^{x}\) 与 \(\cos x\) 各自印象取 \(c=1/2\) 或 \(-1/2\)，都会留下非零二次误差。

易错点

① 乘积漏项：二次项要同时算 \(e^{x}\) 的 \(x^{2}/2\) 乘 1，与 1 乘 \(\cos x\) 的 \(-x^{2}/2\)，两项相加为 0。

② 把 \(\cos x\) 展开写到一次项就收工：\(\cos x\) 无一次项，但二次项参与乘积，不能省略。

③ 符号方向：\(\cos x\) 的二次系数是 \(-1/2\)，与 \(e^{x}\) 的 \(+1/2\) 对冲，符号写反就会算成 \(c=1\)。

考向

乘积型逼近（\(e^{x}\cos x\)、\(e^{x}\sin x\)、\((1+x)\ln(1+x)\)）的固定动作：各因子写到目标阶，乘开后按次数合并同类项。系数相消的级别常是命题点，对表时必须把该级数值写出来，不能凭奇偶性猜测。

变式

变式 若多项式只取 \(1+x\)（二次项系数固定为 0）近似 \(e^{x}\cos x\)，判断误差主部是几阶，是否满足 \(o(x^{2})\)。

答案：误差主部 \(-x^{3}/3\)，是 \(O(x^{3})\)，满足 \(o(x^{2})\)。本题二次系数本就相消为 0，去掉 \(cx^{2}\) 项不影响 \(o(x^{2})\) 口径下的合格性；若口径收紧到 \(o(x^{3})\)，则现有多项式仍缺 \(x^{3}\) 项。

第 0 题 逼近·对数嵌套 P109

【冯建轩】在 \(x=0\) 附近用 \(D(x)=a+bx\) 近似 \(\ln(1+\sin x)\)，使误差为 \(o(x)\)，求 a,b。

答案：\(a=0\)，\(b=1\)。内层 \(\sin x\) 在 0 处为 0，对数展开的常数项随之取 0，一次系数由两层复合共同锁定为 1。
解析

识别类型：对数套正弦的复合逼近，误差口径只到 \(o(x)\)，只需对齐常数项与一次项，二次及以上并入余项即可。

\[ \sin x=x+O(x^{3}),\qquad \ln(1+u)=u-\frac{u^{2}}{2}+O(u^{3}). \]

令 \(u=\sin x=x+O(x^{3})\)，代入后 \(u^{2}=x^{2}+O(x^{4})\)，在 \(o(x)\) 口径下二次项及以上全部保留在余项里：

\[ \ln(1+\sin x)=x+O(x^{2}). \]

与 \(D(x)=a+bx\) 逐级比较，匹配方程组为

\[ a=0,\qquad b=1. \]

代入复核：残余主部为 \(-x^{2}/2\) 量级，整体 \(O(x^{2})=o(x)\)。常数项务必取 0：\(\ln(1+0)=0\)，若误取 \(a=1\)，误差在 \(x\to0\) 时趋于 1，连 \(o(1)\) 都不满足。

对照指数复合 \(e^{\sin x}\)，外层在 0 处取 1 而对数外层取 0，两类题常数项的处理方向相反；对表前先写清外层在 \(u=0\) 的取值，再定 \(a\)。

易错点

① 常数项误取 1：对数在 0 处取值为 0，与 \(e^{u}\) 在 0 处取 1 不要混淆。

② 一次系数多算：复合中 \(\ln\) 的一次系数 1 乘 \(\sin x\) 的一次系数 1，结果是 1，没有额外缩放。

③ 口径越界计算：本题只需对齐到 \(x\)，把 \(-u^{2}/2\) 的二次贡献算进 \(b\) 属多余，不改变一次系数。

考向

低口径逼近（\(o(x)\)）是复合题最容易得分的一档：内层函数在 0 处的值决定常数项，两层一阶导数之积决定一次系数。变体常把内层换成 \(\tan x\)、\(\arcsin x\)，或把外层换成 \(e^{u}\)、\(\arctan u\)，对表顺序不变。

变式

变式 若把多项式追加 \(cx^{2}\) 项、口径提高到 \(o(x^{2})\)，求 c；并写出此时误差主部阶数。

答案：\(c=-1/2\)。\(\ln(1+\sin x)=x-x^{2}/2+O(x^{3})\)，二次系数 \(-1/2\)；配好后残余 \(O(x^{3})=o(x^{2})\)，原有 \(a=0\)、\(b=1\) 不变。

第 0 题 逼近·四次匹配 P109

【冯建轩】在 \(x=0\) 附近用 \(E(x)=a+bx^{2}+cx^{4}\) 近似 \(\dfrac{\sin x}{x}\)，使误差为 \(o(x^{4})\)，求 a,b,c。

答案：\(a=1\)，\(b=-\dfrac{1}{6}\)，\(c=\dfrac{1}{120}\)。商式偶次展开到四次，三个偶次系数与多项式逐项对齐，残余从六次项起。
解析

识别类型：四次口径的偶次商式逼近。误差 \(o(x^{4})\) 要求对齐到 \(x^{4}\)，因目标为偶函数，奇次系数两侧同为 0，只需对三个偶次系数列方程。

\[ \sin x=x-\frac{x^{3}}{6}+\frac{x^{5}}{120}+O(x^{7}). \]

除以 \(x\) 并补定义到 0 点：

\[ \frac{\sin x}{x}=1-\frac{x^{2}}{6}+\frac{x^{4}}{120}+O(x^{6}). \]

与 \(E(x)=a+bx^{2}+cx^{4}\) 逐级比较，匹配方程组为

\[ a=1,\qquad b=-\frac{1}{6},\qquad c=\frac{1}{120}. \]

代入复核：配好后残余主部为 \(-x^{6}/5040\) 量级，整体 \(O(x^{6})=o(x^{4})\)。四次系数 \(1/120\) 来自 \(\sin x\) 的五次项除以 \(x\)，漏掉这一层除法就会把 \(c\) 算成五次项系数本身。

同口径若把目标换成 \(\tan x/x\)，二次系数为 \(1/3\)、四次系数为 \(2/15\)，对表步骤完全一致，只更换展开式与对应方程，解题框架不变。

易错点

① 除法降次忘记：\(\sin x\) 的 \(x^{5}/120\) 除以 \(x\) 才是 \(x^{4}/120\)，直接抄五次项系数会错位一次。

② 奇偶错位：商式为偶，多项式也只含偶次项；若多项式混入奇次项，奇次系数目标为 0，强制令其为 0 即可。

③ 余项阶数误判：对齐到四次后残余是六次项，不要写成 \(O(x^{5})\)，偶次目标不含五次项。

考向

高次口径逼近与二次口径是同一套对表动作，只是多列几级方程。常见偶次商式的系数符号固定：\(\sin x/x\) 的二次项为负、四次项为正；\((1-\cos x)/x^{2}\) 二次项为负。变体多为把口径从 \(o(x^{2})\) 提到 \(o(x^{4})\)，追加锁定一个高次系数。

变式

变式 本题与近似 \(\sin x/x\) 的二次口径题目标函数相同；口径从 \(o(x^{2})\) 提到 \(o(x^{4})\) 后，追加锁定的是哪一级系数，取多少？

答案：追加锁定 \(x^{4}\) 项，系数 \(1/120\)。二次口径下 \(a=1\)、\(b=-1/6\) 不变，四次口径再由 \(x^{4}/120\) 定 \(c=1/120\)，残余 \(O(x^{6})=o(x^{4})\)。

第 0 题 逼近·缺项无解 P109

【冯建轩】在 \(x=0\) 附近用 \(F(x)=ax+bx^{3}\) 近似 \(\sin(x^{2})\)，使误差为 \(o(x^{3})\)，求 a,b。

答案：不存在这样的 a,b。目标函数最低次非零项是 \(x^{2}\)，而多项式只有一次项与三次项，\(x^{2}\) 系数无人匹配；无论 a,b 取何值，误差主部始终为 \(x^{2}\)，不属 \(o(x^{3})\)。
解析

识别类型：奇偶与缺项双重错位的逼近题。先展开复合函数 \(\sin(x^{2})\)，按 \(o(x^{3})\) 口径列出 \(1,x,x^{2},x^{3}\) 各级系数，再检查多项式每一级是否有人对应。

\[ \sin u=u-\frac{u^{3}}{6}+O(u^{5}),\qquad u=x^{2}. \]

代入 \(u=x^{2}\)：

\[ \sin(x^{2})=x^{2}-\frac{x^{6}}{6}+O(x^{10}). \]

与 \(F(x)=ax+bx^{3}\) 逐级比较：常数项两侧均为 0；一次项 \(a=0\)；二次项目标系数为 1，多项式该级系数为 0，方程 \(0=1\) 矛盾；三次项 \(b=0\)。

\[ a=0,\qquad 0=1\ (\text{矛盾}),\qquad b=0. \]

误差验算：即便取 \(a=b=0\)，误差即 \(\sin(x^{2})\) 本身，主部 \(x^{2}\)，除以 \(x^{3}\) 得 \(1/x\)，\(x\to0\) 时绝对值趋于无穷，不满足 \(o(x^{3})\)。多项式形状缺 \(x^{2}\) 项是结构性缺陷，调系数无法弥补。

易错点

① 只对齐低次项：一次、三次系数能解出 \(a=b=0\)，但二次项矛盾被忽略，就会误判成有解。

② 复合展开错位：\(\sin(x^{2})\) 的首项是 \(x^{2}\)，不要照 \(\sin x\) 写成首项 \(x\)。

③ 把缺项当成自由：无人匹配的非零系数无法靠调参数消去，只能改多项式形状，结论应写无解而不是留空。

考向

判无解的两类典型：常数项无人匹配（目标在 0 处非零而多项式无常数项）；中间次系数无人匹配（如本题 \(x^{2}\) 项）。检验动作固定为逐次列方程，出现矛盾等式即判假，再用主部除以 \(x^{k}\) 的极限验证误差阶确实不够。

变式

变式 要在 \(o(x^{3})\) 口径下逼近 \(\sin(x^{2})\)，多项式形状至少应补入哪一项？该项系数取多少？

答案：需补入 \(x^{2}\) 项，系数为 1。形如 \(ax+cx^{2}+bx^{3}\) 的多项式对齐后 \(a=0\)、\(c=1\)、\(b=0\)，残余主部 \(-x^{6}/6=o(x^{3})\)；只靠现有一次、三次项无法配平二次级。

第 0 题 逼近·双曲余弦 P109

【冯建轩】在 \(x=0\) 附近用 \(G(x)=a+bx^{2}\) approximate \(\cosh x\)，使误差为 \(o(x^{2})\)，求 a,b。

答案：\(a=1\)，\(b=\dfrac{1}{2}\)。双曲余弦是偶函数，展开只含偶次项，常数项与二次项分别对齐，残余从四次项起。
解析

识别类型：双曲函数的 Taylor 逼近。\(\cosh x\) 与 \(\cos x\) 的偶次展开结构相同，差别在二次项符号为正；按 \(o(x^{2})\) 口径对齐常数与二次两级。

\[ \cosh x=\frac{e^{x}+e^{-x}}{2}=1+\frac{x^{2}}{2}+O(x^{4}). \]

展开中一次项系数为 0，与多项式缺一次项恰好对应；与 \(G(x)=a+bx^{2}\) 逐级比较，匹配方程组为

\[ a=1,\qquad b=\frac{1}{2}. \] \[ G(x)-\cosh x=-\frac{x^{4}}{24}+O(x^{6})=o(x^{2}). \]

代入复核：配好后残余主部 \(x^{4}/24\)，除以 \(x^{2}\) 趋于 0，满足 \(o(x^{2})\)。注意与 \(\cos x\) 对照记忆：\(\cos x=1-x^{2}/2+\cdots\)，二次系数为负；\(\cosh x\) 二次系数为正，符号方向不要互换。

双曲函数的系数可由 \(e^{x}\) 与 \(e^{-x}\) 平均直接验算：两式相加后奇次项抵消、偶次项加倍再除以 2，常数项与二次项即可从指数展开读出。

易错点

① 符号混淆：双曲余弦二次项为 \(+x^{2}/2\)，写成 \(-1/2\) 就与 \(\cos x\) 颠倒。

② 常数项漏配：\(\cosh 0=1\)，多项式常数项必须取 1，不能因为目标是偶函数就只留二次项。

③ 余项阶数：对齐到二次后残余是四次项，不是三次项，偶函数不含奇次项。

考向

双曲函数在考研逼近题中常与三角函数成对出现：\(\cosh x\) 对 \(\cos x\)、\(\sinh x\) 对 \(\sin x\)，展开骨架相同、偶次项符号相反。变体多为互换目标函数或把口径提到 \(o(x^{4})\)，追加锁定四次系数 \(1/24\)。

变式

变式 把目标换成 \(\cos x\)，仍用 \(a+bx^{2}\) 型多项式、口径 \(o(x^{2})\)，求 b，并与本题二次系数比较符号。

答案：\(b=-1/2\)。\(\cos x=1-x^{2}/2+O(x^{4})\)，常数项同为 \(a=1\)；本题 \(\cosh x\) 的 \(b=+1/2\)，二者二次系数符号相反，是双曲函数与三角函数的固定区别。

第 0 题 逼近·乘积奇次 P109

【冯建轩】在 \(x=0\) 附近用 \(H(x)=a+bx+cx^{2}\) 近似 \(e^{x}\sin x\)，使误差为 \(o(x^{2})\)，求 a,b,c。

答案：\(a=0\)，\(b=1\)，\(c=1\)。乘积在 0 处取值为 0，常数项取 0；一次项来自 \(\sin x\) 的首项，二次项由 \(e^{x}\) 的一次项乘 \(\sin x\) 的一次项给出。
解析

识别类型：指数乘正弦的乘积逼近。两因子分别写到二次项，相乘后截断到二次；本题常数项为 0，与 \(e^{x}\cos x\) 一题的常数项为 1 形成对照。

\[ e^{x}=1+x+\frac{x^{2}}{2}+O(x^{3}),\qquad \sin x=x+O(x^{3}). \]

相乘并保留不超过二次的部分：常数项 \(1\cdot0=0\)；一次项 \(1\cdot x=x\)；二次项只来自 \(x\cdot x=x^{2}\)。

\[ e^{x}\sin x=x+x^{2}+O(x^{3}). \]

与 \(H(x)=a+bx+cx^{2}\) 逐级比较，匹配方程组为

\[ a=0,\qquad b=1,\qquad c=1. \]

代入复核：配好后残余主部为 \(x^{3}/3\) 量级，整体 \(O(x^{3})=o(x^{2})\)。二次系数 \(c=1\) 不要漏算：它来自两因子一次项相乘，若只取 \(e^{x}\) 的常数项乘 \(\sin x\)，二次项会被误算成 0。

易错点

① 常数项误取 1：\(\sin 0=0\)，乘积在 0 处为 0，多项式常数项必须取 0。

② 二次项漏乘：\(x\cdot x\) 贡献 \(x^{2}\)，是本题 \(c=1\) 的唯一来源，漏掉就得到 \(c=0\) 的错误解。

③ 混淆姊妹题：\(e^{x}\cos x\) 常数项为 1、二次项相消；\(e^{x}\sin x\) 常数项为 0、二次项为 1，两题不要串。

考向

乘积题对表时按次数列一张小表：常数项只来自两因子常数相乘，一次项来自常数乘一次与一次乘常数，二次项来自常数乘二次、一次乘一次、二次乘常数三部分。同一骨架还可换成 \(\ln(1+x)\sin x\)、\((1+x)e^{x}\) 等组合。

变式

变式 若多项式不含常数项（形如 \(bx+cx^{2}\)）近似 \(e^{x}\sin x\)，在 \(o(x^{2})\) 口径下是否影响求解？写出 b,c。

答案：不影响。目标函数常数项本就为 0，多项式去掉常数项后仍可对齐，\(b=1\)、\(c=1\)，残余 \(O(x^{3})=o(x^{2})\)；只有目标常数项非零时，缺常数项的多项式才会无解。

第 0 题 逼近·偶次高次 P110

在 \(x=0\) 附近用 \(I(x)=ax^{2}+bx^{4}\) 近似 \(1-\cos x\)，使误差为 \(o(x^{4})\)，求 a,b。

答案：\(a=\dfrac{1}{2}\)，\(b=-\dfrac{1}{24}\)。目标函数在 0 处取值为 0，常数项两侧同为 0，不构成缺项；二次、四次两个偶次系数与多项式逐项对齐。
解析

识别类型：偶次目标配偶次多项式的四次口径逼近。先写 \(1-\cos x\) 到四次，检查常数项是否需要多项式承担，再对二次、四次两级列方程。

\[ \cos x=1-\frac{x^{2}}{2}+\frac{x^{4}}{24}+O(x^{6}). \]

于是

\[ 1-\cos x=\frac{x^{2}}{2}-\frac{x^{4}}{24}+O(x^{6}). \]

常数项目标为 0，多项式无常数项，自动对齐；一次项两侧同为 0。与 \(I(x)=ax^{2}+bx^{4}\) 比较，匹配方程组为

\[ a=\frac{1}{2},\qquad b=-\frac{1}{24}. \]

代入复核：残余主部 \(x^{6}/720\)，整体 \(O(x^{6})=o(x^{4})\)。本题常数项不冲突，是因为 \(1-\cos 0=0\)；若目标换成 \(\cos x\)，常数项 1 无人匹配，同形状多项式才会无解。

与商式 \((1-\cos x)/x^{2}\) 对照：后者整体除以 \(x^{2}\) 后常数项为 \(1/2\)，本题未做除法，最低次非零项是二次项，两级口径下多项式形状的要求随之不同。

易错点

① 常数项误判：把 \(1-\cos x\) 在 0 处的值当成 1，会错判无解；实际 \(1-\cos 0=0\)，多项式不带常数项恰好匹配。

② 四次系数符号：\(-x^{4}/24\)，\(b\) 为负，照抄 \(\cos x\) 的 \(+1/24\) 就符号相反。

③ 余项阶数：对齐到四次后残余为六次项，偶次目标不含五次项，不要写成 \(O(x^{5})\)。

考向

判断常数项是否冲突，先算目标函数在 0 处的函数值，而不是看表达式里有没有常数数字。\(1-\cos x\)、\(\sin x-x\)、\(\arctan x-x\) 在 0 处都取 0，可配无常数项多项式；\(\cos x\)、\(e^{x}\)、\(\ln(1+x)\) 一类则必须配常数项。

变式

变式 若同形状 \(ax^{2}+bx^{4}\) 多项式改为近似 \(\cos x\)，仍要求 \(o(x^{4})\)，判断是否存在这样的 a,b，并说明理由。

答案：不存在。\(\cos x\) 常数项为 1，多项式无常数项，常数级无人匹配；误差在 \(x\to0\) 时趋于 1，连 \(o(1)\) 都不满足，更不可能是 \(o(x^{4})\)。

第 0 题 逼近·反正弦线性 P110

【冯建轩】在 \(x=0\) 附近用 \(J(x)=a+bx\) 近似 \(\arcsin x\)，使误差为 \(o(x)\)，求 a,b。

答案：\(a=0\)，\(b=1\)。反正弦在 0 处取 0，一阶导数为 1，线性逼近即切线 \(y=x\)，残余从三次项起。
解析

识别类型：反三角函数的一阶 Taylor 逼近。\(o(x)\) 口径只锁常数项与一次项，对应函数值与一阶导数值；直接用导数算系数与展开对表结论一致。

\[ \arcsin x=x+\frac{x^{3}}{6}+O(x^{5}). \]

函数值 \(\arcsin 0=0\) 给常数项，导数 \((\arcsin x)'|_{x=0}=1\) 给一次项。与 \(J(x)=a+bx\) 比较，匹配方程组为

\[ a=0,\qquad b=1. \] \[ J(x)-\arcsin x=-\frac{x^{3}}{6}+O(x^{5})=o(x). \]

代入复核：残余主部 \(x^{3}/6\)，除以 \(x\) 得 \(x^{2}/6\to0\)，满足 \(o(x)\)。反三角函数的一次系数都是 1：\(\arcsin x\)、\(\arctan x\) 在 0 处切线斜率同为 1，差别从三次项才开始。

导数路径交叉验证：\((\arcsin x)'=1/\sqrt{1-x^{2}}\)，在 0 处取值 1，与展开对表所得 \(b=1\) 一致；常数项由函数值 \(\arcsin 0=0\) 给出，两条路径结论相同。

易错点

① 常数项误取 1：\(\arcsin 0=0\)，不要与 \(\arcsin 1=\pi/2\) 一类特殊值混淆。

② 一次系数多配：导数在 0 处为 1，不是 \(1/\sqrt{1-x^{2}}\) 在别处的取值。

③ 残余阶数：反正弦是奇函数，无二次项，线性逼近的残余从三次项起，不是二次项。

考向

一阶口径逼近本质就是求切线：常数项取 \(f(0)\)，一次项取 \(f'(0)\)。反三角族中 \(\arcsin x\) 与 \(\arctan x\) 的线性项相同，二次项均为 0，三次系数分别为 \(1/6\) 与 \(-1/3\)，提高口径后差异才显现。

变式

变式 用一次多项式近似 \(\arctan x\) 并要求 \(o(x)\)，写出多项式；若口径提到 \(o(x^{3})\)，还需补入哪一项、系数取多少？

答案：一次逼近为 \(y=x\)；提到 \(o(x^{3})\) 需补 \(x^{3}\) 项，系数 \(-1/3\)（\(\arctan x=x-x^{3}/3+O(x^{5})\)）。与 \(\arcsin x\) 相比，二者三次系数符号相反。

第 0 题 逼近·高斯四次 P110

【冯建轩】在 \(x=0\) 附近用 \(K(x)=a+bx^{2}+cx^{4}\) 近似 \(e^{-x^{2}}\)，使误差为 \(o(x^{4})\)，求 a,b,c。

答案：\(a=1\)，\(b=-1\)，\(c=\dfrac{1}{2}\)。把 \(e^{u}\) 的展开式中的 \(u\) 换成 \(-x^{2}\)，偶次系数逐项对表，残余从六次项起。
解析

识别类型：指数套偶次幂的复合逼近。令 \(u=-x^{2}\)，套用 \(e^{u}=1+u+u^{2}/2+O(u^{3})\)，展开结果只含偶次项，与多项式形状一致。

\[ e^{u}=1+u+\frac{u^{2}}{2}+O(u^{3}),\qquad u=-x^{2}. \]

代入并保留到四次：

\[ e^{-x^{2}}=1-x^{2}+\frac{x^{4}}{2}+O(x^{6}). \]

与 \(K(x)=a+bx^{2}+cx^{4}\) 逐级比较，匹配方程组为

\[ a=1,\qquad b=-1,\qquad c=\frac{1}{2}. \]

代入复核：残余主部 \(-x^{6}/6\)，整体 \(O(x^{6})=o(x^{4})\)。二次系数由 \(u=-x^{2}\) 直接给出为 \(-1\)，四次系数来自 \(u^{2}/2=x^{4}/2\)，两层贡献不要合并错位。

同法可验 \(e^{x^{2}}\)：展开为 \(1+x^{2}+x^{4}/2+O(x^{6})\)，仅二次项符号相反，四次项同为正；若口径再提到 \(o(x^{6})\)，本题追加锁定的六次系数为 \(-1/6\)。

易错点

① 符号跟着指数走：\(e^{-x^{2}}\) 二次项为负，\(e^{x^{2}}\) 二次项为正，指数内符号决定偶次项符号。

② 四次系数漏层：\(x^{4}/2\) 来自 \(u^{2}/2\)，不是指数展开的 \(u\) 项，漏掉平方层就会把 \(c\) 算成 0。

③ 奇偶错位：目标为偶函数，多项式也只含偶次项；一次、三次系数两侧同为 0。

考向

复合指数 \(e^{\pm x^{2}}\) 是高频目标，系数规律固定：常数 1、二次项 \(\pm1\)、四次项 \(1/2\)。变体多为改指数内符号、提高口径到 \(o(x^{6})\)（追加六次系数 \(-1/6\)），或把外层换成 \(\cos x^{2}\) 一类偶次函数。

变式

变式 设目标为 \(e^{\omega x^{2}}\)，用 \(a+bx^{2}+cx^{4}\) 型多项式在 \(o(x^{4})\) 口径下逼近，已得 \(b=-1\)、\(c=1/2\)，反求参数 \(\omega\) 与常数项 a。

答案：\(\omega=-1\)，\(a=1\)。由 \(e^{\omega x^{2}}=1+\omega x^{2}+\omega^{2}x^{4}/2+O(x^{6})\)，\(b=\omega=-1\)，\(c=\omega^{2}/2=1/2\) 自洽；常数项恒为 \(1\)，与 \(\omega\) 无关。

第 0 题 逼近·对数乘积 P110

【冯建轩】在 \(x=0\) 附近用 \(L(x)=a+bx+cx^{2}\) 近似 \((1+x)\ln(1+x)\)，使误差为 \(o(x^{2})\)，求 a,b,c。

答案：\(a=0\)，\(b=1\)，\(c=\dfrac{1}{2}\)。先展开 \(\ln(1+x)\)，再与 \(1+x\) 相乘截断到二次，常数项为 0，一次、二次系数分别对齐。
解析

识别类型：线性因子乘对数的乘积逼近。对数展开到二次，乘开后按次数合并；本题在 0 处取值为 0，常数项与无常数项的要求一致。

\[ \ln(1+x)=x-\frac{x^{2}}{2}+\frac{x^{3}}{3}+O(x^{4}). \]

乘以 \(1+x\)，保留不超过二次的部分：

\[ (1+x)\ln(1+x)=x+\frac{x^{2}}{2}+O(x^{3}). \]

与 \(L(x)=a+bx+cx^{2}\) 逐级比较，匹配方程组为

\[ a=0,\qquad b=1,\qquad c=\frac{1}{2}. \]

代入复核：残余主部 \(-x^{3}/6\)，整体 \(O(x^{3})=o(x^{2})\)。二次系数 \(1/2\) 来自两部分：对数自身的 \(-x^{2}/2\)，加上 \(x\cdot x\) 的 \(+x^{2}\)，合并为 \(+x^{2}/2\)，只算其中一层会符号或数值出错。

导数路径交叉验证：令 \(g(x)=(1+x)\ln(1+x)\)，则 \(g(0)=0\)、\(g'(x)=\ln(1+x)+1\) 故 \(g'(0)=1\)、\(g''(x)=1/(1+x)\) 故 \(g''(0)=1\)，二次系数 \(g''(0)/2!=1/2\)，与展开对表一致。

易错点

① 二次项漏乘：\(x\cdot x\) 的贡献必须计入，单看对数展开会把 \(c\) 算成 \(-1/2\)。

② 常数项误取 1：\((1+0)\ln 1=0\)，多项式常数项取 0，不要被因子 \(1+x\) 里的 1 带偏。

③ 一次系数：\(\ln(1+x)\) 一次项为 1，乘 1 后仍是 1，因子 \(x\) 不参与一次项。

考向

乘积展开的系数合并要逐次列项：二次项来源有常数乘二次、一次乘一次、二次乘常数三条路径。本题是对数族代表，同类骨架还有 \((1+x)e^{x}\)、\((1-x)\ln(1-x)\)，换符号后二次项方向相应改变。

变式

变式 把多项式追加 \(x^{3}\) 项 \(d x^{3}\)，在 \(o(x^{3})\) 口径下近似 \((1+x)\ln(1+x)\)，求 d。

答案：\(d=-1/6\)。展开到三次：\((1+x)\ln(1+x)=x+x^{2}/2-x^{3}/6+O(x^{4})\)，三次系数 \(-1/6\)；原有 \(a=0\)、\(b=1\)、\(c=1/2\) 不变，残余 \(O(x^{4})=o(x^{3})\)。

第 0 题 逼近·差函数匹配 P110

【冯建轩】在 \(x=0\) 附近用 \(M(x)=ax+bx^{2}\) 近似 \(e^{x}-\cos x\)，使误差为 \(o(x^{2})\)，求 a,b。

答案：\(a=1\)，\(b=1\)。两函数分别展开后相减，常数项抵消，一次项为 1，二次项由 \(e^{x}\) 的 \(1/2\) 与 \(\cos x\) 的 \(+1/2\) 合并为 1。
解析

识别类型：两函数之差的 Taylor 逼近。分别展开到二次，相减时注意 \(\cos x\) 前是减号，其各项符号在差式中反向；多项式无常数项，先确认差函数常数项是否为 0。

\[ e^{x}=1+x+\frac{x^{2}}{2}+O(x^{3}),\qquad \cos x=1-\frac{x^{2}}{2}+O(x^{4}). \]

两式相减，常数项 \(1-1=0\)：

\[ e^{x}-\cos x=x+x^{2}+O(x^{3}). \]

与 \(M(x)=ax+bx^{2}\) 逐级比较，匹配方程组为

\[ a=1,\qquad b=1. \]

代入复核：残余主部 \(x^{3}/6\)，整体 \(O(x^{3})=o(x^{2})\)。二次系数 \(b=1\) 是两层之和：\(e^{x}\) 的 \(x^{2}/2\) 减去 \(\cos x\) 的 \(-x^{2}/2\)，即 \(1/2+1/2=1\)；漏了减号反向就会算成 0。

导数路径交叉验证：令 \(h(x)=e^{x}-\cos x\)，则 \(h(0)=0\)、\(h'(x)=e^{x}+\sin x\) 故 \(h'(0)=1\)、\(h''(x)=e^{x}+\cos x\) 故 \(h''(0)=2\)，二次系数 \(h''(0)/2!=1\)，与展开对表所得 \(b=1\) 一致。

易错点

① 减号反向：\(-\cos x\) 把 \(\cos x\) 的二次项 \(-1/2\) 翻成 \(+1/2\)，二次系数合并为 1，不是 \(1/2-1/2=0\)。

② 常数项漏验：差式常数项 \(1-1=0\)，与无常数项多项式匹配；若两因子常数不等，缺常数项即无解。

③ 一次系数：只来自 \(e^{x}\) 的 \(x\)，\(\cos x\) 无一次项，故 \(a=1\)。

考向

差函数逼近与乘积题同样逐次对表，但要先处理整体减号带来的符号翻转。常见组合还有 \(e^{x}-\sin x\)、\(\cos x-\sin x\)；判断有无解先看 0 处函数值之差是否为 0，再逐级比对系数。

变式

变式 取 \(a=1\)、\(b=1\) 后，本题误差主部是几阶？三次系数是多少？

答案：残余主部 \(x^{3}/6\)，属 \(O(x^{3})=o(x^{2})\)；三次系数 \(1/6\) 来自 \(e^{x}\) 的 \(x^{3}/6\)（\(\cos x\) 无三次项）。若口径提到 \(o(x^{3})\)，才需补 \(x^{3}\) 项并取该系数。

第 0 题 逼近·商式偶次 P110

【冯建轩】在 \(x=0\) 附近用 \(N(x)=a+bx^{2}\) 近似 \(\dfrac{\tan x}{x}\)，使误差为 \(o(x^{2})\)，求 a,b。

答案：\(a=1\)，\(b=\dfrac{1}{3}\)。商式在 0 处按极限补定义为 1，偶次展开的二次系数来自 \(\tan x\) 的三次项除以 \(x\)，对齐后残余从四次项起。
解析

识别类型：可去奇点处商函数的偶次逼近，与 \(\sin x/x\) 同骨架，差别只在分子展开的系数。先写 \(\tan x\) 到三次，除以 \(x\) 后截断到二次。

\[ \tan x=x+\frac{x^{3}}{3}+O(x^{5}). \]

除以 \(x\) 并在 0 处补定义：

\[ \frac{\tan x}{x}=1+\frac{x^{2}}{3}+O(x^{4}). \]

与 \(N(x)=a+bx^{2}\) 逐级比较：常数项 \(a=1\)，一次项两侧同为 0，二次项 \(b=1/3\)。匹配方程组为

\[ a=1,\qquad b=\frac{1}{3}. \]

代入复核：残余主部 \(2x^{4}/15\)，整体 \(O(x^{4})=o(x^{2})\)。二次系数 \(1/3\) 由 \(\tan x\) 的三次项 \(x^{3}/3\) 降次得到，不要照抄 \(\tan x\) 展开式本身；对照 \(\sin x/x\) 的二次系数 \(-1/6\)，符号与数值都不同。

导数路径亦可验证：商式在 0 处极限为 1 给常数项，其偶次展开的二次系数由分子三阶导数决定，对表结果与除法展开一致。

易错点

① 降次错位：\(\tan x\) 的 \(x^{3}/3\) 除以 \(x\) 才是 \(x^{2}/3\)，直接把三次系数写进 \(b\) 会次数错位。

② 常数项漏配：\(\tan x/x\) 在 0 处极限为 1，多项式常数项取 1，不能只配二次项。

③ 符号混淆：\(\tan x/x\) 二次项为正，\(\sin x/x\) 二次项为负，两题商式分子不同，符号不要互串。

考向

商式逼近先补定义再展开，偶次商式配偶次多项式。高频对照组：\(\sin x/x\)（二次系数 \(-1/6\)）、\(\tan x/x\)（\(1/3\)）、\((1-\cos x)/x^{2}\)（常数 \(1/2\)、二次系数 \(-1/24\)），系数表记熟后对表可直接落方程。

变式

变式 把本题与 \(\sin x/x\) 的二次口径题对照：二者二次系数各取多少，符号为何相反？

答案：\(\tan x/x\) 的二次系数 \(+1/3\)，\(\sin x/x\) 为 \(-1/6\)。分子 \(\tan x\) 三次项为正 \(+x^{3}/3\)，\(\sin x\) 三次项为负 \(-x^{3}/6\)，除以 \(x\) 后符号随分子保留。

第 0 题 逼近·倍角余弦 P110

【冯建轩】在 \(x=0\) 附近用 \(O(x)=a+bx+cx^{2}\) 近似 \(\cos(2x)\)，使误差为 \(o(x^{2})\)，求 a,b,c。

答案：\(a=1\)，\(b=0\)，\(c=-2\)。倍角余弦是偶函数，一次项强制为 0；二次项由 \(\cos u\) 的 \(-u^{2}/2\) 代入 \(u=2x\) 得到 \(-2x^{2}\)。
解析

识别类型：复合余弦的 Taylor 逼近。令 \(u=2x\)，套用 \(\cos u=1-u^{2}/2+O(u^{4})\)，回代后按 \(x\) 的次数合并；多项式虽含一次项，目标为偶函数，一次系数方程会给出 \(b=0\)。

\[ \cos u=1-\frac{u^{2}}{2}+O(u^{4}),\qquad u=2x. \]

代入并保留到二次：

\[ \cos(2x)=1-2x^{2}+O(x^{4}). \]

与 \(O(x)=a+bx+cx^{2}\) 逐级比较，匹配方程组为

\[ a=1,\qquad b=0,\qquad c=-2. \]

代入复核：残余主部 \((2/3)x^{4}\)，整体 \(O(x^{4})=o(x^{2})\)。二次系数 \(-2\) 含一层平方缩放：\(-(2x)^{2}/2=-2x^{2}\)，漏掉倍角平方就会把 \(c\) 算成 \(-1/2\)。

对照 \(\cos x\) 的二次系数 \(-1/2\)，倍角 \(2x\) 使二次系数乘以 \(2^{2}=4\)，即 \(-1/2\times4=-2\)；一般 \(\cos(\omega x)\) 的二次系数为 \(-\omega^{2}/2\)。

易错点

① 倍角缩放漏平方：\(\cos(2x)\) 的二次系数是 \(-2\)，不是 \(-1/2\)，也不是 \(-1\)。

② 一次项留非零：目标为偶函数，一次系数两侧同为 0，方程给出 \(b=0\)，不要保留自由参数。

③ 常数项：\(\cos 0=1\)，\(a=1\)；偶次复合在 0 处的函数值与外层函数在 0 处一致。

考向

复合三角函数的系数随内层缩放按幂次变化：一次系数乘 \(\omega\)，二次系数乘 \(\omega^{2}\)，三次系数乘 \(\omega^{3}\)。变体常改内层系数（\(\cos(kx)\)、\(\sin(kx)\)）或改口径到四次，方法仍是先写外层展开再回代内层。

变式

变式 若多项式 \(a+bx+cx^{2}\) 近似 \(\cos(\omega x)\)，要求二次系数为 \(-2\)，求 \(\omega\)；此时一次系数 b 取何值？

答案：\(-\omega^{2}/2=-2\) 得 \(\omega=2\)（取正）；一次系数 \(b=0\)，因 \(\cos(\omega x)\) 为偶函数，两侧一次项均为 0。

第 0 题 逼近·正弦减项 P110

【冯建轩】在 \(x=0\) 附近用 \(P(x)=ax^{2}+bx^{3}\) 近似 \(\sin x-x\)，使误差为 \(o(x^{3})\)，求 a,b。

答案：\(a=0\)，\(b=-\dfrac{1}{6}\)。目标函数消去一次项后从三次项起，二次系数为 0 故 \(a=0\)，三次系数 \(-1/6\) 由多项式 \(x^{3}\) 项承担。
解析

识别类型：目标函数低阶抵消后的高阶逼近。先展开 \(\sin x\)，减去 \(x\) 消去一次项，再按 \(o(x^{3})\) 口径对齐常数、二次、三次各级。

\[ \sin x=x-\frac{x^{3}}{6}+\frac{x^{5}}{120}+O(x^{7}). \]

减去 \(x\)：

\[ \sin x-x=-\frac{x^{3}}{6}+\frac{x^{5}}{120}+O(x^{7}). \]

与 \(P(x)=ax^{2}+bx^{3}\) 逐级比较：常数项两侧均为 0；一次项两侧均为 0；二次项目标系数为 0，故 \(a=0\)；三次项 \(b=-1/6\)。匹配方程组为

\[ a=0,\qquad b=-\frac{1}{6}. \]

代入复核：残余主部 \(x^{5}/120\)，整体 \(O(x^{5})=o(x^{3})\)。二次系数 \(a=0\) 不是漏配，而是目标函数该级本就为 0；多项式里的 \(x^{2}\) 项在本题被对齐成零系数。

与 \(\tan x-\sin x\) 对照：两者都从三次项起，但三次系数分别为 \(-1/6\) 与 \(+1/2\)，符号与数值来自各自分子的展开，不可互抄。

易错点

① 三次系数符号：\(\sin x-x\) 的三次项为 \(-x^{3}/6\)，\(b\) 为负，不要照抄 \(\sin x\) 的系数符号。

② 二次项误配：目标无二次项，\(a=0\)；不要因为多项式含 \(x^{2}\) 项就强行给非零系数。

③ 残余阶数：对齐到三次后残余是五次项，奇函数不含四次项，余项不要写成 \(O(x^{4})\)。

考向

「函数减自身切线」型目标（\(\sin x-x\)、\(\arctan x-x\)、\(\tan x-x\)）首非零项都在三次，系数分别为 \(-1/6\)、\(-1/3\)、\(1/3\)。口径为 \(o(x^{3})\) 时多项式只需配三次项；提到 \(o(x^{5})\) 再追加五次系数。

变式

变式 若改用 \(ax+bx^{3}\) 型（不含 \(x^{2}\) 项）多项式近似 \(\sin x-x\)，仍要求 \(o(x^{3})\)，求 a,b，并与本题解比较。

答案：\(a=0\)，\(b=-1/6\)，与本题解相同。目标一次、二次系数均为 0，多项式去掉 \(x^{2}\) 项后不影响对齐；残余主部 \(x^{5}/120=o(x^{3})\)。只有目标某缺项级别系数非零时，去掉对应项才会造成无解。

第 0 题 逼近·复合商式 P110

【冯建轩】在 \(x=0\) 附近用 \(Q(x)=a+bx^{4}\) 近似 \(\dfrac{\sin x^{2}}{x^{2}}\)，使误差为 \(o(x^{4})\)，求 a,b。

答案：\(a=1\)，\(b=-\dfrac{1}{6}\)。复合商式在 0 处补定义为 1，展开只含偶次项，四次系数由 \(\sin(x^{2})\) 的三次复合项除以 \(x^{2}\) 得到。
解析

识别类型：复合正弦除以同次幂的商式逼近。令 \(u=x^{2}\)，先写 \(\sin u/u\) 的展开，再回代 \(u=x^{2}\)；口径 \(o(x^{4})\) 要求对齐常数项与四次项，二次项目标为 0。

\[ \sin u=u-\frac{u^{3}}{6}+O(u^{5}),\qquad u=x^{2}. \]

除以 \(u=x^{2}\) 并补定义到 0 点：

\[ \frac{\sin x^{2}}{x^{2}}=1-\frac{x^{4}}{6}+O(x^{8}). \]

与 \(Q(x)=a+bx^{4}\) 逐级比较：常数项 \(a=1\)；二次项两侧同为 0；四次项 \(b=-1/6\)。匹配方程组为

\[ a=1,\qquad b=-\frac{1}{6}. \]

代入复核：残余主部 \(x^{8}/120\)，整体 \(O(x^{8})=o(x^{4})\)。四次系数 \(-1/6\) 来自 \(\sin u\) 的 \(-u^{3}/6\) 除以 \(u\) 后留 \(-u^{2}/6\)，再代 \(u=x^{2}\) 得 \(-x^{4}/6\)；两层除法与复合不要错位。

对照 \(\sin x/x\)：后者二次系数 \(-1/6\)，本题把 \(x\) 换成 \(x^{2}\)，同一系数落到四次项，骨架相同、次数整体抬高一倍。

易错点

① 复合次数错位：\(\sin(x^{2})\) 首项为 \(x^{2}\)，除以 \(x^{2}\) 后常数项为 1，不要写成首项 \(x^{2}\)。

② 系数次数落错：\(-1/6\) 配在 \(x^{4}\) 项，不是 \(x^{2}\) 项；多项式形状本身也只提供四次项。

③ 余项阶数：对齐到四次后残余是八次项，偶次复合不含五、六、七次项，不要写成 \(O(x^{6})\)。

考向

复合商式是普通商式的次数平移：\(\sin x/x\) 的系数表整体把 \(x^{k}\) 换成 \(x^{2k}\)。变体常把内层换成 \(x^{3}\) 或把外层换成 \(\tan(x^{2})/x^{2}\)，解题顺序仍是先补定义、再展开复合、最后对表系数。

变式

变式 把本题展开与 \(\sin x/x\) 对照：两者是怎样的次数平移关系？写出同位置系数的对应。

答案：次数整体翻倍。\(\sin x/x=1-x^{2}/6+x^{4}/120+O(x^{6})\)，\(\sin x^{2}/x^{2}=1-x^{4}/6+x^{8}/120+O(x^{12})\)；同位置系数相同（\(1,-1/6,1/120\)），\(x^{k}\) 换成 \(x^{2k}\)，骨架不变。

第 0 题 逼近·正切指数 P110

【冯建轩】在 \(x=0\) 附近用 \(R(x)=a+bx+cx^{2}\) 近似 \(e^{\tan x}\)，使误差为 \(o(x^{2})\)，求 a,b,c。

答案：\(a=1\)，\(b=1\)，\(c=\dfrac{1}{2}\)。内层 \(\tan x\) 在 0 处一阶系数为 1，指数复合后常数、一次、二次三级系数与 \(e^{\sin x}\) 在本口径下相同。
解析

识别类型：指数套正切的复合逼近。先写 \(\tan x\) 到一次，再套 \(e^{u}=1+u+u^{2}/2+O(u^{3})\)；口径 \(o(x^{2})\) 下内层三次项不参与前三级系数。

\[ \tan x=x+O(x^{3}),\qquad e^{u}=1+u+\frac{u^{2}}{2}+O(u^{3}). \]

令 \(u=\tan x=x+O(x^{3})\)，回代后 \(u^{2}=x^{2}+O(x^{4})\)：

\[ e^{\tan x}=1+x+\frac{x^{2}}{2}+O(x^{3}). \]

与 \(R(x)=a+bx+cx^{2}\) 逐级比较，匹配方程组为

\[ a=1,\qquad b=1,\qquad c=\frac{1}{2}. \]

代入复核：残余主部为 \(x^{3}/2\) 量级，整体 \(O(x^{3})=o(x^{2})\)。二次系数 \(1/2\) 来自 \(u^{2}/2\)，与内层是 \(\sin x\) 还是 \(\tan x\) 无关——两者在 0 处一阶系数同为 1，本口径下前三级重合。

若口径提到 \(o(x^{3})\)，内层三次项的差异才进入系数表：\(\tan x\) 三次系数 \(1/3\) 会改变目标三次项，届时需追加 \(x^{3}\) 项并重新对表。

易错点

① 二次项漏层：\(u^{2}/2\) 贡献 \(x^{2}/2\)，只展 \(e^{u}\) 的一次项会把 \(c\) 算成 0。

② 常数项取值：\(e^{0}=1\)，\(a=1\)；不要按内层 \(\tan 0=0\) 把常数项取成 0。

③ 口径越界代入：\(\tan x\) 的 \(x^{3}/3\) 在 \(o(x^{2})\) 口径下不影响前三级，提前代入三次系数属多余计算。

考向

指数复合在低口径下只看内层的函数值与一阶系数：内层 \(u(0)=0\)、\(u'(0)=1\) 时，\(e^{u}\) 的前三级恒为 \(1+x+x^{2}/2\)。变体多为提高口径到三次，迫使内层二阶、三阶差异显现；或把外层换成 \(\ln(1+u)\)、\(\arctan u\) 一类在 0 处取 0 的函数。

变式

变式 若现有二次多项式 \(a+bx+cx^{2}\) 要把误差压到 \(o(x^{3})\) 近似 \(e^{\tan x}\)，还缺哪一级项？写出目标函数的三次系数。

答案：缺 \(x^{3}\) 项。展开到三次：\(e^{\tan x}=1+x+x^{2}/2+x^{3}/2+O(x^{4})\)，三次系数 \(1/2\)（由 \(u\) 的三次项 \(x^{3}/3\) 与 \(u^{3}/6\) 的 \(x^{3}/6\) 合并）；二次多项式配不出该级，残余主部 \(x^{3}/2\) 不是 \(o(x^{3})\)。

第 0 题 逼近·反正切减项 P110

在 \(x=0\) 附近用 \(S(x)=ax+bx^{3}\) 近似 \(\arctan x-x\)，使误差为 \(o(x^{3})\)，求 a,b。

答案：\(a=0\)，\(b=-\dfrac{1}{3}\)。目标函数消去一次项后从三次项起，一次系数为 0 故 \(a=0\)，三次系数 \(-1/3\) 由多项式 \(x^{3}\) 项承担。
解析

识别类型：反正切减自身切线的高阶逼近。先展开 \(\arctan x\)，减去 \(x\) 消去一次项，按 \(o(x^{3})\) 口径对齐一次、二次、三次各级；多项式含一次项，目标一次系数为 0，方程强制 \(a=0\)。

\[ \arctan x=x-\frac{x^{3}}{3}+\frac{x^{5}}{5}+O(x^{7}). \]

减去 \(x\)：

\[ \arctan x-x=-\frac{x^{3}}{3}+\frac{x^{5}}{5}+O(x^{7}). \]

与 \(S(x)=ax+bx^{3}\) 逐级比较：常数项两侧均为 0；一次项 \(a=0\)；二次项两侧同为 0；三次项 \(b=-1/3\)。匹配方程组为

\[ a=0,\qquad b=-\frac{1}{3}. \]

代入复核：残余主部 \(x^{5}/5\)，整体 \(O(x^{5})=o(x^{3})\)。三次系数 \(-1/3\) 与 \(\sin x-x\) 的 \(-1/6\) 不同，二者分子展开的三次项系数各有出处，不可互抄。

题面到此为止，紧随其后的「题型五 求解 \(\lim\theta(x)\) 问题」是下一段标题的排版挤行，不并入本题；本题只在 \(o(x^{3})\) 口径下求 a,b。

易错点

① 一次项误留：目标是 \(\arctan x-x\)，一次项已被消去，\(a=0\)；若误按 \(\arctan x\) 本体对齐，会写成 \(a=1\)。

② 三次系数混淆：\(\arctan x-x\) 三次系数 \(-1/3\)，\(\sin x-x\) 为 \(-1/6\)，两者不要串。

③ 越界并题：页内同排的题型五标题不属于本题题干，不要把 \(\theta\) 极限问题写进求解过程。

考向

「减切线」族的三次系数固定对照：\(\sin x-x\) 为 \(-1/6\)，\(\arctan x-x\) 为 \(-1/3\)，\(\tan x-x\) 为 \(1/3\)。口径 \(o(x^{3})\) 时多项式配到三次即可；提到 \(o(x^{5})\) 再追加五次项，反正切的五次系数为 \(1/5\)。

变式

变式 若口径从 \(o(x^{3})\) 提到 \(o(x^{5})\)，现有 \(ax+bx^{3}\) 型多项式还需补入哪一项？系数取多少？

答案：需补 \(x^{5}\) 项，系数 \(1/5\)。\(\arctan x-x=-x^{3}/3+x^{5}/5+O(x^{7})\)；现有多项式配不出五次系数，残余主部 \(x^{5}/5\) 除以 \(x^{5}\) 趋于 \(1/5\)，不满足 \(o(x^{5})\)。
