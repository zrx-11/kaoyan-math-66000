## 3. 卡片骨架（逐字照抄结构，只替换内容）
```html
<article class="q" id="q<题号>">
  <div class="q-head">
    <span class="qno">第 <题号> 题</span>
    <span class="qtype">题型标签</span>
    <span class="qsrc">P<页码></span>
  </div>
  <div class="stem">
    <p>题干原文……</p>
    <div class="opts"><p>(A) ...</p><p>(B) ...</p><p>(C) ...</p><p>(D) ...</p></div>
  </div>
  <div class="answer">答案：X</div>
  <div class="block sol"><div class="block-title">解析</div><p>……</p>\[ ... \]</div>
  <div class="block pit"><div class="block-title">易错点</div><p>……</p></div>
  <div class="block trend"><div class="block-title">考向</div><p>……</p></div>
  <div class="block var"><div class="block-title">变式</div><p><b>变式</b> ……</p><p class="var-ans">答案：……</p></div>
</article>
```
- `div class="opts"` 只在选择题出现；填空/解答题删掉。
- 不要写 `style` 属性、不要新增标签或 class。

## 4. 内容标准（这套书的深度）
1. **题干**：与页面逐字一致，不跳题、不改题、不编题。数学式：行内 `\( ... \)`，行间 `\[ ... \]`；分数用 `\dfrac`。
2. **答案**：以页面上「【冯建轩简版答案】」为准。
3. **解析**：完整可复现推导，不少于 200 字。结构：识别类型（0/0、∞/∞、1^∞、∞−∞、无穷小比较、夹逼、中值定理……）→ 每步变形与所用定理/等价无穷小/泰勒阶数 → 关键步骤讲清「为什么这么变形」。
4. **易错点**：至少 1 条真坑（符号、阶数、左右极限、条件漏用、干扰项构造）。
5. **考向**：2–4 句，说清这类题在考研里的位置和联动知识点。
6. **变式**：1 道**换了考法**的题（不是原题改数字），附答案。
7. 语言：简体中文理工科书面语；不要口语、感叹号、「我们」。

## 5. 红线（出现过反例，逐条执行）
- **推导必须自洽**：展开式每一阶系数要能自己验算通过。禁止「过程略」「略繁琐」「存疑」「待核」「以书上答案为准」「此处略」「自行补充」「TODO」等字样（自检脚本会拦）。
- **不许自我更正过程**：变式必须一次算对；不要把「先写成 X，后改为 Y」留在正文。
- **题面与书上答案明显矛盾**（漏印/错印）时，不用 HTML 注解放，改写成卡片内可见块：
  ```html
  <div class="block caveat"><div class="block-title">校勘说明</div><p>按题面计算为…，书给答案为…，疑为漏印。</p></div>
  ```
  同时 `答案` 行仍写书上答案。
- **去公式后正文 ≥520 字**（自检脚本按汉字/字符数算，公式命令不计）。
- 卡片数 = 你页段内题数；不许为了凑数拆题或合并题。
