## 五、内容标准
1. **题干**逐字照图，不改写、不精简、不补条件。书上若出现「Tex translation failed」或漏印，原文如实标注 `（页面此处排版失败，原式无法辨读）`，**绝不杜撰原式**。
2. **答案栏是唯一答案出口**：书上答案与复算一致就直接写；不一致时答案栏写**复算值**，并在答案之后、解析之前插校勘块（见下）。书的错值不得留在答案栏。
3. 校勘块固定写法：
```html
<div class="block caveat"><div class="block-title">校勘说明</div><p>书给 X，复算 Y（一句关键理由），以复算为准。</p></div>
```
4. **解析** 550–900 字，必须是可复现推导：先点明识别类型（0/0、∞/∞、\(1^\infty\)、\(\infty-\infty\)、夹逼、单调有界、中值定理、定积分定义、无穷小比较……），再写每步变形与依据，关键一步讲清「为什么这样变形」。**禁止凑字数**：不得出现「本题与前面题相同」「其余同理」「不再赘述」「过程略」「略去」「待核」「核对」「自行补充」「TODO」「以书上答案为准」。
5. **易错点**至少 1 条，必须是本题真正的坑（符号、阶数、左右极限、条件漏用、错误选项的构造逻辑）。
6. **考向** 2–4 句：题型定位、近年考法、与哪些题/知识点联动（可引用本段或邻段题号）。
7. **变式**必须换考法（不是原题改数字），附 `var-ans` 答案且一次算对；变式与答案都要独立成段 `<p>`。
8. 语言：简体中文理工书面语，不用「我们」、不用感叹号、不口语化。
