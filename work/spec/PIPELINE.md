把指定的 PDF 页面图像逐页读完，为其中**每一道题**写出一张 HTML 卡片，写入指定的输出文件。

## 输出

- 文件内容**只包含一串 `<article class="q">` 卡片**，不要 `<html>`、`<head>`、`<body>` 外壳，不要 CSS，不要目录。
- 卡片之间空一行。题号顺序严格递增。

## 卡片结构（照抄这个骨架）
```html
<article class="q" id="q<题号>">
  <div class="q-head">
    <span class="qno">第 <题号> 题</span>
    <span class="qtype">题型标签</span>
    <span class="qsrc">P<页码></span>
  </div>
  <div class="stem">
    <p>题干原文……</p>
    <div class="opts">          <!-- 只有选择题才写；填空题/解答题删掉这一块 -->
      <p>(A) ...</p><p>(B) ...</p><p>(C) ...</p><p>(D) ...</p>
    </div>
  </div>
  <div class="answer">答案：X</div>
  <div class="block sol">
    <div class="block-title">解析</div>
    <p>完整推导……</p>
    \[ ... \]                  <!-- 行间公式 -->
  </div>
  <div class="block pit">
    <div class="block-title">易错点</div>
    <p>……</p>
  </div>
  <div class="block trend">
    <div class="block-title">考向</div>
    <p>……</p>
  </div>
  <div class="block var">
    <div class="block-title">变式</div>
    <p><b>变式</b> ……</p>
    <p class="var-ans">答案：……</p>
  </div>
</article>
```
样式已由站点 CSS 统一处理，**不要写 style 属性、不要写 class 以外的自定义标签**。

## 内容标准（全套深度）
1. **题干**：与页面完全一致，一字不改。数学式用 LaTeX：行内 `\( ... \)`，行间 `\[ ... \]`。分数用 `\dfrac`，保证渲染清晰。
2. **答案**：以页面上「【冯建轩简版答案】」为准。若你的计算与之不符，**仍写书上答案**，并在卡片末尾加一行注释：`<!-- 存疑：我的计算为 X，理由：… -->`。
3. **解析**：不少于 200 字，必须是**可复现的完整推导**：
   - 先点明「识别类型」（0/0、∞/∞、1^∞、∞-∞、无穷小比较、夹逼、中值定理……）；
   - 再写每一步变形与所用定理/等价无穷小/泰勒阶数；
   - 关键一步要说清「为什么这么变形」，不要只丢公式；
   - 能用一行公式说清的，不要堆三段废话。
4. **易错点**：至少 1 条，写这道题真正的坑（符号、阶数、左右极限、条件漏用、常见错误选项的构造逻辑）。
5. **考向**：这道题在考研里的位置——属于哪类题型、近年以什么形式出现、与哪些知识点联动。2-4 句。
6. **变式**：给 1 道真正换了考法的题（不是原题改数字），附答案。变式要能直接拿来练。
7. 语言：简体中文，理工科书面语，不要口语、不要感叹号、不要「我们」。公式要正确、符号要用对（\(\ln\)、\(\lim\)、\(\to\)、\(\infty\)）。

## 质量红线
- **不许跳题**：页面上出现的每一道题都要有卡片，题号必须与页面一致。
- **不许编题**：看不清楚时可以放大重读该页，但绝不能凭印象补题。
- **不许偷懒**：解析写成「由等价无穷小可得」一句话了事，等于没写。
- 完成后自查：卡片数 = 该区间的题目数；`id="qN"` 无重复；LaTeX 括号闭合。

## 交回
最后回复：输出文件绝对路径、覆盖题号区间、卡片数量、存疑题号清单（没有就写「无」）。
