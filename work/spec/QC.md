# 抽检与质检工序（QC）

## 三层检查

| 层 | 触发 | 手段 | 拦什么 |
|---|---|---|---|
| 结构闸门 | 每次构建 | `work/gate.py` | 缺板块、缺题干/答案、LaTeX 不配对、口水词（核对/过程略/存疑）、变式无答案 |
| 自动可疑扫描 | 每轮抽检前 | `work/audit.py` | 页码错位（题号↔页码偏差>2）、解析雷同（相似度>0.8）、答案与推导数值不一致（低置信，仅参考） |
| 人工抽检 | 每轮 | `work/spotcheck.py` 出看板，逐题打开页面图比对 | 题干错字、答案错、推导不自洽 |

## 台账

`work/checks.csv`：`q,page,verdict,note,time`
verdict：`pass` 通过 / `fixed` 我改过并复算 / `fail` 需返工 / `skip` 书印问题已写校勘

## 隔离机制

- `work/quarantine.json`：结构闸门拦下的题
- `work/fixlist.json`：台账判 `fail` 的题
- 两者都会被 `build_site.py` 排除，**不进站**，但留在源文件里等返工；修好后从台账改判 `fixed` 即自动回站。

## 每轮节奏

1. `python3 work/spotcheck.py --round N` 生成看板（滚动窗口，每窗 4 题，可疑优先）
2. 逐题打开 `work/pages/jixian/p00NNN.png` 比对题干、答案、复算解析
3. 结果写回台账，重跑 `python3 work/spotcheck.py`
4. `bash work/publish.sh` 发布（已自动串联 spotcheck→gate→build→push）

## 答案校验基准（2026-11-19 第三方复核后确立）

- **书答不可作校验基准，须回题面复算。** 书印答案与卡内解析都可能是错的：第二册 t02 首次第三方复核（100 张，pass 93 / fixed 3 / fail 4）中 4 张 fail 全部源于「拿书答当基准」，无一张是独立复算发现的。
- 定值流程：从题干自身复算（sympy 级数/极限 + 数值两档互证），卡值 = 复算值；与书答不符时按「答案栏改复算值/结论 + 校勘块（书值 / 错因 / 复算值）」处理，校勘块紧跟 `answer`、在 `sol` 前，不塞进解析。
- 变式同样要独立复算：var-ans 必须能被变式解析末步算出；中间量（如 `S_n^n` 随 n 变化的取值）不得当答案。
- 已知易错族（本册已复发两次以上）：递推平方化时丢掉二次修正项（`1/n³`、`1/n²` 版各一次）；变式漏网格因子（`1/n=(1/2)(2/n)`）；代换后积分上限未随之改变；连乘开 n 次方时把外层 n 倍丢掉、使发散题被算成有限值。

## 台账改判与措辞清理（2026-11-19 立）

- **改判必须走 `work/verify/rerecord.py`**（强制覆盖）；`work/merge_ledger.py` 只用于新段首次落账。原因：`merge_ledger` 的「已有优先」排序假设 fixed 永远比 pass 新且更可信，但实际存在「fixed 记的是解析修复、答案本来就对」这一类卡（2116/2125/2127），被 pass 覆盖就丢了纠错历史。
- **措辞清理单独计数**：跨卡题号互引改成方法层面描述属 polish，不计入 fixed / changed。互引本身不算缺陷，只在它可能干扰读者定位（指向远处的卡、已改判的卡、或与本题结论无关）时才改。
- **`skip` 定义（2026-11-19 裁决，覆盖旧义）**：`skip` 只留给**题面不可用**——原书漏印、印刷损坏不可恢复（1305/1315/1325 的 `Tex translation failed`）、答案栏空白（Q195）。这类卡不需要校勘块。
- **题面可读时只有两态：答案或结论错 → `fixed`；对 → `pass`。没有第三态。** 因此「带 caveat 块却记 `skip`」= 书答错且已校勘，一律转 `fixed`（note 写「书印错，已校勘」）。「带块却记 `pass`」同样是记账错，直接改判 `fixed`。
- **`fixed` 须带 `fix_type`**：`answer`（书答错、答案栏改过）/ `sol`（只修解析，答案与书答一致）。后者是为保留纠错历史而保留的 `fixed`，不得被 `pass` 覆盖。
- **`verdict` 记的是「书的质量」，不是「我们干了什么」（2026-11-19 二次裁决）**：
  - 书答错 → `fixed/answer`；
  - 书答对、但**书印解析/分步有错** → `fixed/sol`；
  - 书答对、书解析也对，只是我们加厚 / 压薄 / 改措辞 → **`pass`**，改动记 note 的「治理：」段，不改判定；
  - 书没错、错在**我们自己的卡**（如 q256/q267/q286 卡内式子写错）→ **`pass`** + 「自纠」记录，不算书错。
  - 依据：`fixed` 若混进「加厚」，用户会把数字读成「这么多张书印错」，且与 caveat 块数对不上（曾出现 fixed 568 > caveat 478）。校对5 的 67 张「只加厚」据此回退 pass。
- **「有校勘块却记 pass / skip」= 记账错，一律按上表改判。** 该路径已三次验证为最高效入口，不必重推。反面同样成立：**`fixed` 无块 = 账实不符强信号**，须逐张查是书错未记、还是我们自纠被误记（401–500 段 403/442、501–600 段 531/538/579/596 均属后者，已改回 pass）。

## 构建与工具实测（2026-11-19 立，反直觉且会致错）

- **同号多份的生效规则分两层**（`build_site.py`）：
  1. **同目录内**（`t01/*.html` 按文件名升序）→ `if n in cards and len(m.group(0)) <= len(cards[n]): continue`，**保留 article 更长者**，等长取先出现的文件；
  2. **跨目录**（`EXTRA_FRAG` 的 `jixian` → `jixian/parts`）→ `cards.update(c2)`，**无条件后压前**，不看长度。
  - 因此「胜出份」不能只看长度，也不能只看目录顺序，必须按题号逐查。**改卡前先确认该题号当前由哪一份承载。**
  - 现状：`work/fragments/jixian/parts/` 已于 17:06 清空（dup 249→117），第 2 层当前无对象，但规则不得从文档里删。
  - **多副本段收尾动作**：定稿后把整块 `<article>` 逐字写入所有同号旧件，`sha1` 逐题校验；只改一份会导致页面转去加载旧副本（501–530 的 30 题即此类，已 30/30 同步）。
- **`plainlen.py` 的 sol 切片是 `block sol` → `block pit`**：校勘块插在 `sol` 与 `pit` 之间会被算进 sol 字数（q341 裸 sol 413，插块后 664，直接 gate exit 1）。**校勘块只能放 `answer→caveat→sol`（`sol` 前）或 `pit` 之后。**
- **caveat 块的类名是 `class="block caveat"`，不是 `class="caveat"`**——按后者统计会漏，曾误报「全段零校勘块」而实际 5 张带块记成 skip。
- **字数口径唯一**：`work/qa/plainlen.py` 的 **plain 字数**（sol 301–420 硬线、整卡 ≥620），不是汉字数。自建计数常比它少算约 13 字，导致「自判达标」而实际超限（q1–100 因此曾 34 张超限、q201–300 33 张）。**派活与验收一律写「按 plainlen 的 plain 字数口径」，不写「字数」。**
- **写回的基底必须是「pre-merge 时刻的当前磁盘版本」，不是开工时的 `before` 快照。** 两轮连续踩同一个坑：校对5 的合并脚本首版以 `before/` 为基底整文件重建，单组 `--apply` 就把别组已合并的内容还原；校对8 的 `seg-799-807.html` 被另一批次**整文件写回**，q1101–1105 的加厚被覆盖三次（每次回到 plain 526–539）。**越界校验仍对 `before/`，重建基底对 pre-merge。** 派活时范围必须**按承载文件对齐**，不让两段共享同一文件。
- **同一文件被两段共享时**（如 `seg-799-807.html` 载 1053–1105、`seg-766-773.html` 载 867–913、`seg-734-741.html` 载 674–721）：只能按题号块合并，收尾把「本人范围外零改动」逐条 D 出去。

## 复原题面的判据（2026-11-19 三线对照后定死）

- **可复原**：页面图上符号**逐字可辨**（如 741：根指数、外层 e 都在），且复原结果**能被书印答案自证**（e/2 与书答一致）。note 写死：「题干按页面残片复原，符号逐字核对，复原结果与书印答案自洽。」
- **不可复原**：页面显示**不可辨乱码 / 源码残片**（`Tex translation failed`：955/964 型），一律判 `skip`，解析改「同类题通用做法 + 变式复核」，**不得按书答反推题面**（校对3 的执行体一度这么干，已撤）。
- 区别只有一条：**符号能不能逐字读出来**。判杜撰必须亮页面图证据。
