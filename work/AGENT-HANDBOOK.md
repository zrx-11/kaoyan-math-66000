### 这个项目是什么

把冯建轩《考研数学 66000》（12,776 页、约 6.4 万题）做成一份**全书逐题精解的可编辑 HTML 站点**。

### 用户已确认、不可擅自更改的规范

- 逐册推进，不做对话式澄清；
- 答案以**独立复算值为准**，原书给错就写复算值 + 紧跟一个**可见校勘块**（不写 HTML 注释）；
- 卡是**可编辑静态 HTML**，部署 GitHub Pages，定时自动推进；
- 每轮推送站点，过程分产物一并打包；
- 解析写实（300–450 字），不靠填充句凑长度。

## 3. 十条硬口径（违反任何一条都要退回重做）

1. **题干唯一来源是页面图**（150dpi 灰度 PNG）。PDF 文本层**完全不可用**：π、∞、∫、∈ 会丢，分数被打散。
2. **答案栏是唯一答案出口**。书印值错 → 答案栏写复算值，紧跟一个 `class="block caveat"` 校勘块写「书给 X，实为 Y」。
3. **「书给」只认页面图印值**，不许从答案栏、caveat 正文或旧 note 反抄。这是最容易自证清白却出错的一处。
4. **`skip` 唯一含义是「题面不可用」**（缺项不可辨 / `Tex translation failed`）。**skip 卡上不许有 caveat 块**。
5. **`fixed ⇔ caveat` 双向成立**：判 fixed 必须有块；有块（且块写的是书错）就必须是 fixed。
6. **不可辨题面不许复原**。只有「页面符号逐字可读 + 复原结果能被书印答案自证」才可复原（本书仅 q741 属此列）；否则只写「按原书印出的题面：发散（原书疑漏印一项）」，不写任何复原值。
7. **变式独立核**：每张卡的变式（`var`）有自己的 `var-ans` 与解析，两者必须自洽，且不与主问答案混用。
8. **篇幅硬线**：`sol` 301–420 字、整卡 plain ≥620 字、行间公式 `\[` ≥3 处。三条一起验，只看「篇幅在区间」会掩盖公式缺口。
9. **禁词三条**：「核对：」「略去」「待补」出现在卡片里会让 `gate.py` 直接隔离下线。
10. **写 HTML 严禁用 python/shell 做字符串拼接**（反斜杠会被吞，`\frac` 变 `rac`）。一律用文件读写 + 定点 Edit。数学段裸 `<`、`>` 必须先转 `\lt{}`、`\gt{}`。

## 5. 脚本为什么在仓库里也能跑

所有脚本的项目根都从脚本自身位置推导：

```python
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))   # work/*.py → 仓库根
```

站点目录同样自适应：

```python
SITE = f"{ROOT}/kaoyan66000"
if not os.path.isdir(SITE):
    SITE = ROOT        # 仓库自身即站点时，直接写仓库根
```

所以同一套脚本在两种布局下都能跑：
①开发机（`<项目根>/kaoyan66000/` 是站点、`<项目根>/work/` 是工作台）；
②本仓库（站点与 `work/` 同层）。**改动脚本时不要把这层自适应删掉。**

`publish.sh` 只推 `origin main`，需要你自己的远端与凭据；它不含任何 token。

## 6. 推进一个区段：九步（这是本项目 90% 的日常工作）

以「核 q1401–q1500」为例：

1. **定范围、按文件对齐**。先 `python3 work/qa/range_map.py 1401 1500`，看这 100 张落在哪几个分片。**派活必须按文件边界切**：两段共享同一文件时，谁都不许整文件重建，只能按题号块合并。
2. **备份 + 记录 sha1**。`cp -p <file> work/verify/bak-<段>/`，并给每张卡记 sha1，用于事后证明「区间外零改动」。
3. **测基线三维**：旧 verdict 分布、`plainlen.py` 的 sol/整卡/公式数。
4. **扫游离段落**：`python3 work/qa/find_orphans.py <文件>`，有就删（删前留档），删后复核 article 哈希未变。
5. **分片派执行体**（每条只给一个明确题号区间 + 文件），范围含糊会造出空任务烧额度。
6. **块级合并写回**。写回基底 = **pre-merge 时刻的当前磁盘版本**（不是开工快照）；越界校验对 `before/` 快照比。合并后立即重算「段外被改动」，必须报 `none`。
7. **过闸**：`gate_one.py <file> 起 止` + `plainlen.py`。要求 `ALL_IN_RANGE`、`min_plain≥620`、`FAILED 0`。
8. **写台账**：新段首次用 `merge_ledger.py`；**改判（pass↔fixed↔skip）走 `rerecord.py`**，不许手改 csv。
9. **构建 + 发布**：`python3 work/build_site.py` → `python3 work/gate.py`（必须 `failed=0`）→ `bash work/publish.sh` → `git ls-remote origin refs/heads/main` 比对本地 HEAD。

### 判定的判定（verdict 怎么给）

| 情况 | verdict | 动作 |
|---|---|---|
| 书答对、卡也答对，只加厚/压薄/补公式 | `pass` | note 写「治理：…」 |
| 书答错，卡已写复算值 + caveat | `fixed/answer` | 答案栏=复算值 |
| 书答对，但书印解析/分步错，卡改正 | `fixed/sol` | 保留 caveat 说明 |
| 卡自身有错（含变式自误） | `pass` | note 写自纠记录 |
| 题面不可用（不可辨/缺项） | `skip` | **不许有 caveat 块** |

口径演进过三次，细节见 `work/spec/LEDGER.md`。

## 7. 新开一册：从 PDF 到上线

### 7.1 出页面图（唯一可靠的题干来源）

```bash
# 单页/页段，150dpi 灰度；-gray 必须加，彩色会干扰字形判断
pdftoppm -png -r 150 -gray -f 590 -l 700 冯建轩《考研数学66000》最后一舞.pdf work/pages/jixian/p
# 产出形如 p-0590.png / p-00590.png（位数随页数变化，务必 ls 确认实际命名）
```

**已有目录的命名规矩**：第一册 `pages/jixian/p00590.png`（5 位、无连字符）；
第二册 `pages/nxh/p-01096.png`（5 位、带连字符）。新开目录请照抄同册命名，并在 `manifest` 里记明。

150dpi 图上**斜体 n 与 3、根指数与系数**极难分辨，判阶数/系数必须放大 8–10 倍再看。

### 7.2 生成 manifest（题号 ↔ 页码）

```bash
python3 work/build_manifest.py     # 读 PDF 书签，输出 work/manifest/*.json
```

已知缺陷：`jixian_map.json` 的 `q2p` **缺 q101–q150 全部键**；且 `q2p` 在 q1511 附近整体错位
（`q2p[1511]=879` 按「+15」换算指向 p00894，实际 p00894 是 1584–1588）。
**正确做法：`qsrc` 里的 `Pxxx` 数字直接对应 `p00XXX.png`，不要再 +15。** 缺键时一律以卡内 `qsrc` 为准。

### 7.3 分片与生产

- 分片粒度：按**页段**切（`seg-<起页>-<止页>.html`），100 题约 10 页；每个分片只含 `<article>` 卡片，不带任何页面模板。
- 生产一批 25–50 题，**先出题干转录稿**（`work/drafts/stems-<段>.md`）再写卡：逐条抄页面图，抄完回看核对。
- 卡片结构照 `work/templates/gold-1-6.html`，规范见 `work/spec/CARD-FORMAT.md`。
- 生产完立刻 `gate_one.py`，别攒到最后。

### 7.4 建站

`build_site.py` 从 `content/lectures/<册>/t0N.html` 的标题里解析专题名（形如「《极限》2650 题」），
所以**新专题必须先有讲解页骨架**，否则该专题不会出现在站点上。每 100 题一页，自动分页、自动生成目录与进度。

## 8. 雷区清单

### 8.1 数学内容（已实测复发的 15 族，开工按类型点名排查）

1. **三角嵌套换序**：`tan(sin)−sin(tan) = +x⁷/30`，`sin(tan)−tan(sin) = −x⁷/30`，两者不可混用。代表 665/755/765/1010/1061/1086/1174/1191/1355/1665/1682。
2. **变式答案栏自误被记 fixed** —— 全书最高频的**记账**错（403/442、531–596、716–765、819–895、1005–1099、1201–1289、1300–1377）。判据：块里写的是变式值而不是书印值。
3. **相消失败**：首阶抵消后残留项没算，误报有限值。521/543/544、670/684、795、1023/1081/1096、1622/1651/1698/1726。
4. **`ln(1+u)−u+u²/2 = u³/3`**（真值恒 1/3）：1176 书 −1/6、1188 −1/6、1195 −1/3、1189 书 0、1190 书 1/2。
5. **cos 底幂指把发散主部当常数**：`ln cos x / x^p` 主部是 `−1/(2x^{p−2})` → 真值全 0。902/912/922/932/942。
6. **多因子幂指比只减一个 S**：`ln L = S − mS`。925/935/945（915 两因子是书答正确的对照组）。
7. **伪 1^∞ 底数≠1**：914 偶次→双侧 +∞，944 奇次→右 +∞ 左 0→不存在。
8. **Riemann 和线性化**：968/979/989/999。
9. **连乘收敛书给 ∞**：469/479/489/499。
10. **四选项全不成立**：465。
11. **Laplace 渐近取错端点值**：1302 漏 √2、1332 把 π 写成 1/π。1302/1312/1316/1322/1332/1333/1343。
12. **变限积分残项未消尽**：1311/1331/1341、1704/1725。
13. **缺项级数/倍角裂项误套闭式**：1326/1327/1337/1346/1347。
14. **多项式构造反解给了不存在的解**：1320/1330/1340/1350、1709/1727/1793/1794。
15. **主部漏判 cos/sin 成对**：1308/1318（互为对照，1318 书 0 实 1）。1328/1329/1348/1375/1400。

### 8.3 环境与技术坑

- PDF 文本层 → 符号丢失，**永远不用**。
- `python3 work/publish.sh` → SyntaxError，必须 `bash work/publish.sh`。
- Bash heredoc 内含 `%` 会被篡改成 `%!H(MISSING)`；`sleep N && curl` 被拦截；单行 `python3 -c` 引号易不闭合。
- 数学段裸 `<`/`>` 会被当标签吞段 → 全库用 `\lt{}`/`\gt{}`（现存 885 处）。
- LaTeX 控制符损坏（`\arc` 后跟 BEL/TAB）肉眼不可见但渲染错，需字节级扫描。
- 正则扫 card id 若要求行首 `</article>` 会漏缩进闭合的分片 → **必须按 `<article ...>` 起点切片**。
- 相消题别用小 x 直接求值（1633 在 x=1e−3 偏出 4e−6，真值 8.3333e−3）。
- 子智能体自报字数不可信 → 一律用 `work/qa/plainlen.py`。

## 9. 事故与修复（都真实发生过）

### 9.1 整文件写回覆盖（连续多轮，结构性风险）

症状：另一条线用「开工快照」整文件重建，把你刚合进去的改动还原。
实例：`seg-799-807.html` 被整文件写回三次，1101–1105 的加厚每次归零；
`seg-867-878.html` 里 1505 在 21:18 被并行线写回吃掉，退回 sol 446。

处置：
1. **写回基底 = pre-merge 时刻的当前磁盘版本**，永远不要用开工快照；
2. 合并脚本只搬 `<article>` 块，按题号合并，不整文件重建；
3. 合并后立即重算「段外被改动」，要求 `none`；
4. 关键切片另存 `slice-<起>-<止>-final.html` 作重放源。

### 9.2 合并脚本首版自身是事故源

校对5 的合并脚本第一版以 `before/` 快照为基底整文件重建，单组 `--apply` 把别组已合并内容还原，
还连带还原了别线改过的 1101–1105。改为「pre-merge 快照为基底、越界校验对 `before/`」后消失。

### 9.3 空任务子智能体

派执行体**没传范围**，它在被取消前自己跑完了整段，白烧份额度。
**规矩：派任何执行体，subtask 里必须写清题号区间与文件路径。**

### 9.4 「skip 伪装」

旧账写「原书疑漏印一项」判 skip 的 521/543/544，回页面图发现题面完整、书印答案明确，
