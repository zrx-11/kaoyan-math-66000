极限：这一册在考什么

《极限》2650 题是整套书的第一册，也是整张考研数学卷子的地基。它在试卷上的存在形式有三层：

  • 直接考——选择题/填空题里的「求极限」，通常 5 分，年年有；
  • 间接考——导数定义、定积分定义、级数敛散性、无穷小阶的比较，本质都是极限；
  • 暗中考——解答题第一步的「先算个极限看看」，算错就整题崩。

所以这一册的正确用法不是「刷完」，而是把七种未定型的处理动作练成条件反射，看到式子就知道该掏哪件工具。

一、七种未定型与对应武器

所有极限题，先做一次「定型」：把 \(x\to a\) 代进去，看是哪种未定型，再选武器。

  • \(\frac00\) 型：首选等价无穷小替换（乘除因子可换，加减项慎换），其次泰勒展开到分母同阶，最后才洛必达。
  • \(\frac{\infty}{\infty}\) 型：抓主部（最高阶项）最快；含参数的用洛必达；含 \(e^x\)、\(\ln x\)、幂函数的混合式，记住增长速度 \(e^x\gg x^n\gg\ln x\)。
  • \(\infty-\infty\) 型：通分、有理化、提公因子，化成 \(\frac00\) 或 \(\frac\infty\infty\)。根式差一律先有理化。
  • \(0\cdot\infty\) 型：把其中一个因子下放到分母，化成型 1 或型 2。
  • \(1^\infty\) 型：直接用 \(e^{\lim v(u-1)}\)，比取对数快；识别标志是底数 \(\to1\)、指数 \(\to\infty\)。
  • \(0^0\)、\(\infty^0\) 型：必须先取对数 \(e^{v\ln u}\)，因为此时 \(u-1\) 未必是小量。

二、五个工具的适用边界（错用比不会更致命）

  • 等价无穷小：\(x\to0\) 时 \(\sin x\sim x\)、\(\tan x\sim x\)、\(\arcsin x\sim x\)、\(\arctan x\sim x\)、\(\ln(1+x)\sim x\)、\(e^x-1\sim x\)、\(1-\cos x\sim\frac{x^2}{2}\)、\((1+x)^\alpha-1\sim\alpha x\)、\(x-\sin x\sim\frac{x^3}{6}\)、\(\tan x-x\sim\frac{x^3}{3}\)、\(\arcsin x-x\sim\frac{x^3}{6}\)。只许对乘除因子整块替换；加减法里替换会丢掉高阶项，必须用泰勒。
  • 泰勒：展开到「分母的阶」为止。分母 \(x^3\) 就展到 \(x^3\)，展少了得不出值，展多了浪费。常用六式必须背到三阶。
  • 洛必达：只对 \(\frac00\)、\(\frac\infty\infty\) 直接用；用前先做等价替换能少求几次导。每次用完要检查是否仍是未定型。
  • 夹逼：用于 \(n\) 项和的数列极限、含 \(n\) 的取整/最大项问题。关键是找到两侧「同极限」的界。
  • 单调有界：递推数列 \(x_{n+1}=f(x_n)\) 的专用工具，先证有界（数学归纳法），再证单调（作差或作商），最后令 \(n\to\infty\) 解方程 \(A=f(A)\)。

三、数列极限的四条常规路径

  1. 定积分定义：见到 \(\frac1n\sum f\left(\frac{i}{n}\right)\) 或能凑成这个形状的 \(n\) 项和，立刻转成 \(\int_0^1 f(x)\,dx\)。
  2. 夹逼：\(n\) 项和里分母含 \(n\) 与 \(i\) 的，放大缩小各取一个常数极限。
  3. 单调有界：递推式给出的数列，这是唯一正路。
  4. 转化为函数极限：把 \(n\) 换成连续变量 \(x\)，用洛必达或泰勒；注意这招只在能写出对应函数时可用。

四、三类「反问题」

  • 已知极限反求参数：把分子展开到与分母同阶，比对系数；或由「极限存在」推出低阶项系数为零。
  • 已知极限反求另一极限：整体展开后移项，如「\(\frac{\sin6x+xf(x)}{x^3}\to0\) 求 \(\frac{6+f(x)}{x^2}\)」。
  • \(\xi\) 的极限：中值定理写等式 → 解出 \(\xi\) → 泰勒估阶。\(\xi\) 一般不与 \(x\) 同阶，常差一个常数因子。

五、本章最容易丢分的六个点

  1. 加减法里直接用等价无穷小，丢掉高阶项（如 \(x-\sin x\) 直接换成 0）；
  2. \(1^\infty\) 型算成 \(e^{\lim(u-1)}\) 却漏了指数 \(v\)；
  3. 含 \(e^{1/(x-a)}\)、\(\arctan\frac1{x-a}\) 的题不分左右极限；
  4. 洛必达连用时不检查未定型，越求越乱；
  5. 数列极限把「\(n\to\infty\)」当连续变量求导；
  6. 无穷小阶的比较只算比值不看定义域（\(x\to0^+\) 与 \(x\to0\) 有别）。

六、建议的使用顺序

本册按「基础计算 → 未定型分类 → 无穷小阶 → 数列极限 → 反问题 → 综合」排列。建议第一遍只做每组前 30 题，把方法过一遍；第二遍回头做全组，重点看易错点与变式；第三遍只做标了「存疑」和自己算错的题。每一组做完，回到本页对照上面的武器清单，看哪件工具还没练熟。
