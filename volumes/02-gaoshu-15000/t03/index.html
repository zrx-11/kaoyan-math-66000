无穷小：怎么比、跟谁比

无穷小不是「很小的数」，而是「极限为 0 的变量」。这一专题真正考的不是概念，而是阶的估计——谁比谁快、快多少、差几阶。

一、定义与记号

设 \(x\to x_0\) 时 \(\alpha(x)\to0\)、\(\beta(x)\to0\)，且 \(\beta\neq0\)：

  • \(\lim\frac{\alpha}{\beta}=0\)：\(\alpha\) 是 \(\beta\) 的高阶无穷小，记 \(\alpha=o(\beta)\)；
  • \(\lim\frac{\alpha}{\beta}=\infty\)：低阶；
  • \(\lim\frac{\alpha}{\beta}=c\neq0\)：同阶；\(c=1\) 时等价，记 \(\alpha\sim\beta\)；
  • \(\lim\frac{\alpha}{\beta^k}=c\neq0\)：\(\alpha\) 是 \(\beta\) 的 \(k\) 阶无穷小。

二、必须背熟的一阶与高阶等价

\(x\to0\) 时：

一阶：\(\sin x\sim\tan x\sim\arcsin x\sim\arctan x\sim\ln(1+x)\sim e^x-1\sim x\)；

二阶：\(1-\cos x\sim\dfrac{x^2}{2}\)，\(x-\ln(1+x)\sim\dfrac{x^2}{2}\)；

三阶：\(x-\sin x\sim\dfrac{x^3}{6}\)，\(\tan x-x\sim\dfrac{x^3}{3}\)，\(\arcsin x-x\sim\dfrac{x^3}{6}\)，\(\arctan x-x\sim-\dfrac{x^3}{3}\)；

一般式：\((1+x)^\alpha-1\sim\alpha x\)，\(a^x-1\sim x\ln a\)。

三、四条实战原则

  1. 乘除整块替换：\(\dfrac{\sin x}{x}\to1\) 这种整体替换永远安全。
  2. 加减禁止直接替换：\(x-\sin x\) 若把 \(\sin x\) 换成 \(x\) 就得到 0，正确答案是 \(\frac{x^3}{6}\)。判据是「替换后主项是否抵消」——一旦抵消，必须上泰勒。
  3. 阶的比较用比值：比较 \(\alpha,\beta\) 的阶，就算 \(\lim\alpha/\beta\)；结果 0、\(\infty\)、常数分别对应高、低、同阶。
  4. 变上限积分先求导定阶：\(\int_0^x f(t)\,dt\) 的阶比 \(f(x)\) 高一阶，这是积分型无穷小比较的固定动作。

四、常见考法与陷阱

考法有三：①给几个无穷小排序；②求 \(\lim\dfrac{\alpha}{\beta^k}\) 定 \(k\)；③已知 \(\alpha\sim\beta\) 求参数。陷阱集中在两处：一是 \(x\to0^+\) 与 \(x\to0\) 的区别（\(\sqrt{x}\) 只在右侧有定义）；二是「\(o(x)\)」的运算——\(o(x)+o(x^2)=o(x)\)，低阶吸收高阶，写错阶数会导致整题作废。
