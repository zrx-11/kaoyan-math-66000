连续性与间断点：判断顺序比技巧重要

这一专题的题面几乎都在问同一件事：这个函数在这一点长什么样。答法有固定流程，按流程走不会漏。

一、连续的三层定义

  • 点连续：\(\lim\limits_{x\to x_0}f(x)=f(x_0)\)，要求「极限存在 + 函数有定义 + 两者相等」三条同时成立。
  • 左/右连续：\(\lim\limits_{x\to x_0^-}f(x)=f(x_0)\) 或右极限等于函数值。分段函数在分界点必须分左右。
  • 区间连续：开区间内点点连续；闭区间端点要求单侧连续。

二、间断点分类（先算左右极限，再分类）

  • 第一类（左右极限都存在）：相等但 \(\neq f(x_0)\)（或 \(f(x_0)\) 无定义）是可去间断点；不相等是跳跃间断点，跃度 \(=\lim^+-\lim^-\)。
  • 第二类（至少一侧极限不存在）：有一侧趋于无穷是无穷间断点（如 \(1/x\)、\(e^{1/x}\)、\(\tan x\)）；左右振荡无极限是振荡间断点（如 \(\sin\frac1x\)）。

判断顺序：先算左右极限 → 再看是否有限 → 最后比函数值。顺序颠倒极易把无穷间断当成跳跃。

三、三类高频函数形态

  1. 分式：分母为零的点是候选间断点，约分后看是否可去。
  2. 含 \(e^{1/(x-a)}\)、\(\arctan\frac{1}{x-a}\)：这类点在 \(a\) 处两侧走向完全不同（\(+\infty\) 与 \(0\)、\(\frac\pi2\) 与 \(-\frac\pi2\)），必须分左右。
  3. 含 \(|x-a|\)、取整 \([x]\)、分段定义：分界点两侧表达式不同，直接代值。

四、闭区间上连续函数的四大定理

有界性、最值定理、介值定理、零点定理，全部以「闭区间连续」为前提。做题时常见的错误是区间开闭写错（如用 \((0,1)\) 去套零点定理），或者忘了验证端点值异号。

五、易错清单

  • 把「极限存在」直接当成「连续」，漏掉函数值那一条；
  • 分段点不求左右极限，直接代式子；
  • 可去间断点被误判为第二类（因为原式在该点无定义）；
  • 讨论连续性时忘记先确定定义域，在定义域外的点谈连续没有意义。
